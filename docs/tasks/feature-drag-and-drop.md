# [Feature Spec] Drag-and-Drop добавление ярлыков на панель

## 1. Концепция и UX-сценарий

* **Основной сценарий:**
  1. Пользователь выделяет и зажимает левой кнопкой мыши (ЛКМ) файл (`.exe`, ярлык `.lnk`, папку или документ) в Проводнике Windows или на рабочем столе.
  2. Удерживая ЛКМ, нажимает дважды Caps Lock (`Caps-Caps`).
  3. Низкоуровневый хук `WH_KEYBOARD_LL` срабатывает независимо от активного цикла OLE Drag-and-Drop в Windows — панель выезжает у края экрана.
  4. Пользователь перетаскивает файл на панель.
  5. Панель визуально подсвечивает зону вставки (пунктирная рамка или подсветка слота).
  6. Пользователь отпускает ЛКМ (`Drop`).
  7. Приложение считывает путь, извлекает метаданные, сохраняет обновленный список в `config.json` и сразу отображает новый ярлык в интерфейсе.

## 2. Логика назначения параметров

* **Название (`name`):** извлекается из имени файла без расширения (для `.lnk` считывается имя ярлыка).
* **Горячая клавиша (`key`):**
  * Берется первая латинская буква из названия файла.
  * Если она уже занята другим ярлыком — ищется следующая свободная буква в названии.
  * Если все буквы названия заняты или название на кириллице без свободных латинских аналогов — выбирается первая свободная цифра `1..9` или оставляется пустым.
* **Иконка (`icon`):** извлекается автоматически через `SHGetFileInfo` / `ShellIconExtractor`.
* **Повышение прав (`runAsAdmin`):** по умолчанию `false`.

## 3. Обработка краевых случаев

* **Дубликаты:** если сбрасываемый путь уже присутствует в `config.json`, новый элемент не создается; существующий ярлык кратковременно подсвечивается в списке.
* **Неподдерживаемые форматы Drag-and-Drop:** данные, не содержащие формат `DataFormats.FileDrop` (например, перетаскивание произвольного текста или картинок из браузера), игнорируются с установкой `DragEventArgs.Effects = DragDropEffects.None`.
* **Завершение перетаскивания мимо панели:** стандартная отмена drag-операции, панель закрывается по клику вне окна.

## 4. План реализации (после MVP)

1. [ ] Включить `AllowDrop="True"` для `MainWindow.xaml` и контейнера списка.
2. [ ] Реализовать обработчики `DragEnter`, `DragOver`, `DragLeave` с визуальной индикацией (Drop Target Visual).
3. [ ] Реализовать обработчик `Drop` со считыванием `string[] files = (string[])e.Data.GetData(DataFormats.FileDrop)`.
4. [ ] Реализовать алгоритм автоматического выбора свободного `key` (`HotkeyAllocator`).
5. [ ] Добавление в `LauncherConfig` и сохранение через `ConfigService.SaveConfig()`.
