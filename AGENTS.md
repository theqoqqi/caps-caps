# AGENTS.md

## О проекте

- **Проект**: CapsCaps — утилита для быстрого вызова всплывающего дока и мгновенного запуска приложений по двойному нажатию Caps Lock на Windows.
- **Стек**: C# (.NET 8 SDK, `net8.0-windows`), WPF, ModernWpfUI (0.9.6), H.NotifyIcon.Wpf (2.4.1).
- **Сборка**: `dotnet build`.
- **Тесты**: `dotnet test`.
- **Переиспользование кода**: утилиты хранения, сериализации (`JsonFileStorage<T>`) и базовые сервисы переносятся из `QuietShell.Shared` / `QuietShell.Shared.UI` (`P:\RiderProjects\QuietShell`) целиком без изменения исходных контрактов в отдельный проект `CapsCaps.Shared`.

## Архитектура

- **Глобальный хук**: `WH_KEYBOARD_LL` Win32 API в фоновом потоке, пассивно отслеживающий двойной клик Caps Lock (дельта $\le 300$ мс) и перехват хоткеев при активном процессе открытия панели.
- **Единый конвейер открытия**:
  - Двойной Caps Lock переводит лаунчер в состояние `PendingOpen` (таймер задержки 200–300 мс) $\to$ `Opening` (анимация Slide-in + Fade 150–200 мс) $\to$ `Opened`.
  - Нажатие любого зарегистрированного хоткея в любом из этих состояний мгновенно запускает целевой процесс и отменяет/закрывает панель.
- **Хранение конфигурации**:
  - `config.json` рядом с исполняемым файлом.
  - Потокобезопасная сериализация/десериализация (`System.Text.Json`, `WriteIndented = true`).
  - Hot Reload через `FileSystemWatcher`.
  - При повреждении JSON файл на диске не трогается, выдается уведомление, приложение продолжает работу на Last Known Good Config.
- **Жизненный цикл**:
  - Single Instance через именованный `Mutex` (`Global\CapsCaps_SingleInstance_Mutex`).
  - Системный трей Windows (`TaskbarIcon` от `H.NotifyIcon.Wpf`) с пунктами «Открыть config.json» и «Выход».

## Стиль кода (C#)

- **Отступы**: 4 пробела. Табуляция запрещена.
- **Фигурные скобки (K&R / Egyptian Style)**: открывающая скобка `{` пишется на той же строке через пробел.
- **Конструкция `else`**: пишется на новой строке, но её открывающая скобка `{` пишется на той же строке:

  ```csharp
  if (condition) {
      // ...
  }
  else {
      // ...
  }
  ```

- **Тело класса**: сразу после открывающей скобки `{` класса обязательно оставляется одна пустая строка.
- **Однострочные атрибуты**: для коротких свойств и членов атрибуты объявляются в ту же строку в самом начале.
- **Пространства имён и импорты**:
  - Сначала объявляются `using` директивы, затем пустая строка, затем `namespace`.
  - Использовать File-scoped namespaces (`namespace CapsCaps;`).
- **Запятые (Trailing Commas)**: во всех многострочных литералах, массивах, параметрах и аргументах обязательны trailing-запятые.
- **Логические условия**: избегать многострочных громоздких выражений в скобках `if` в пользу отдельных переменных, свойств или guard-методов.
- **Порядок членов и функций (Stepdown Rule)**: код организуется сверху вниз от высокого уровня абстракции к деталям реализации. Методы, вызываемые внутри других методов, обязаны располагаться строго ниже вызывающих их методов.

## Тестирование

- **Фреймворк**: xUnit (.NET 8).
- **Расположение**: `CapsCaps.Tests`.
- **Запуск**: `dotnet test`.
- **Изоляция**: тесты не должны зависеть от внешних файлов окружения или активных окон ОС. Вся логика конфига, состояний и таймеров тестируется через изолированные сервисы.
- **Эмуляция ввода**: для интеграционных тестов хука клавиатуры использовать программную эмуляцию нажатий клавиш через Win32 `SendInput`.
