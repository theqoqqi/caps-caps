## 1. Подстановка буфера обмена в аргументы запуска (`%CLIPBOARD%`)

* **Концепция:**  
  Возможность использовать макрос `%CLIPBOARD%` в поле `arguments` или `path` внутри `config.json`.
* **Пример использования:**
  ```json
  {
    "name": "Поиск в Google",
    "path": "https://www.google.com/search?q=%CLIPBOARD%",
    "key": "G"
  }
  ```
* **UX:**  
  Пользователь выделяет текст в любом документе, нажимает `Ctrl+C`, затем `Caps-Caps + G` — браузер моментально открывается с результатами поиска по выделенному тексту.
* **Технические нюансы:**
  * Чтение буфера обмена через `Clipboard.GetText()` в UI-потоке (`STAThread`).
  * Экранирование спецсимволов при подстановке в URL (`Uri.EscapeDataString`) или аргументы командной строки.
  * Если буфер обмена пуст или содержит не-текстовые данные — запуск с пустым аргументом или базовым URL.

## 2. Фокусировка на уже запущенном окне (Focus Existing Window)

* **Концепция:**  
  Опциональный флаг `"focusExisting": true` в настройках ярлыка. При нажатии хоткея, если процесс программы уже работает, вместо повторного запуска активируется и выводится на передний план его главное окно.
* **Технические нюансы:**
  * Поиск процесса по имени exe через `Process.GetProcessesByName(...)`.
  * Win32 API: `ShowWindowAsync(hWnd, SW_RESTORE)` и `SetForegroundWindow(hWnd)`.
  * Обход ограничения Windows на кражу фокуса (`AllowSetForegroundWindow`).
